Como usar:
1. Extraia todos os arquivos.
2. Abra o arquivo index.html no navegador.
3. Digite o número do candidato e clique em CONFIRMAR.

Teclas do computador:
- Números: digitar voto
- Enter: confirmar
- Esc: corrigir

O projeto funciona localmente, sem depender de imagens externas.

Foto adicional: 90.png -> Dona


CONTADOR DE VOTOS
- Cada voto confirmado é contabilizado automaticamente.
- Candidatos, votos brancos e votos nulos são separados.
- A contagem fica salva no navegador usando localStorage, mesmo após recarregar a página.
